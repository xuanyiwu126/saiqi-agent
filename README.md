赛启｜校园竞赛组队 Agent

面向大学生竞赛场景的智能推荐与组队 Agent。

赛启围绕校园竞赛中的信息分散、赛事选择成本高和跨专业组队困难等问题，构建了从用户画像、主动追问、赛事匹配到组队行动的一体化工作流。

核心能力

用户画像：整合专业、技能、竞赛经历、目标及时间投入等信息

主动追问：当关键信息不足时，补充用户目标、偏好与约束

混合推荐机制：结合模型语义匹配与规则评分进行赛事推荐

可解释推荐：展示匹配依据、风险点与待确认信息

组队闭环：支持推荐后继续进入队伍发布、申请与管理流程

异常回退：智能体异常或返回不完整时提供备用路径，保证核心流程可继续执行
